# COVID-19 Exploratory Data Analysis

## Project Overview
This project performs exploratory data analysis (EDA) on a COVID-19 healthcare dataset using Python.

The analysis focuses on:
- COVID positive case analysis
- Age distribution
- Gender analysis
- ICU admissions
- Mortality trends
- Diabetes and obesity impact
- Correlation heatmaps

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Insights
- Older patients showed higher mortality rates
- ICU admissions were more common among severe cases
- Diabetes and pneumonia were associated with severe outcomes
- Correlation analysis identified relationships among healthcare variables
